ウェブアクセシビリティ試験結果（2026年9月1日）

2026年9月1日公開 セトラスフードテック

本サイトでは、ウェブアクセシビリティの維持・向上を目的として、定期的にアクセシビリティ試験を実施しています。

その取り組みの一環として、JIS X 8341-3:2016（レベルAA）を基準としたアクセシビリティ試験を実施し、本ページでは、その試験結果を公開しています。

概要

本サイトでは、JIS X 8341-3：2016に基づいた試験（自己評価）を実施しました。

本仕様書における「準拠」という表記は、情報通信アクセス協議会ウェブアクセシビリティ基盤委員会「ウェブコンテンツの JIS X 8341-3:2016 対応度表記ガイドライン 2021年4月版」で定められた表記によります。

結果を踏まえ、適合レベルAAを維持するために、継続的にアクセシビリティの確保と向上に取り組んでまいります。

現時点で把握している問題点とその対応方針

手順に基づき試験を行った結果、次の問題点があることを認識しています。課題を少しでも解決し、ウェブアクセシビリティ体制の整備を進めて参ります。

1.4.8 視覚的提示（AAA）；テキストブロックの段落幅（最大値80文字（全角40文字））が指定されていない（※1）
問題点
マルチデバイス対応を実現するためにレスポンシブウェブデザインを導入しており、テキストブロックの段落幅を指定することはできかねます。
対処方法
可読性の担保のために、余白のやフォントサイズのジャンプ率を確保したレイアウトに務めます。
1.4.13 ホバー又はフォーカスで表示されるコンテンツ（AA）；グローバルナビゲーションで、追加コンテンツの非表示や表示の継続が操作できない（※2）
問題点
一定以上の画面サイズ（主にパソコンのデスクトップサイズ）で表示されるグローバルナビゲーションはマウスオーバーでのプルダウンメニューです。そのため、ホバー時にポインタを動かさずにサブメニューの非表示、あるいは、表示の継続ができないため、マウスホバーやキーボードフォーカスでのユーザーのアクセシブルな操作を達成するメカニズムがありません。
対処方法
ナビゲーション機能の代替版の提供として、フッターにサイトマップを設置してユーザビリティを補ってまいります。
2.4.11 隠されないフォーカス（最低限）（AA）、2.4.13 隠されないフォーカス（拡張）（AAA）；グローバルナビゲーションのフォーカス時、コンポーネントの表示が隠れる（※3）
問題点
一定以上の画面サイズ（主にパソコンのデスクトップサイズ）で表示されるグローバルナビゲーションはマウスオーバーでオーバーレイ表示するプルダウンメニューです。そのため、サブメニュー展開時にはコンテンツ内の他のコンポーネントの表示が隠れる場合があります。
対処方法
ナビゲーション機能の代替版の提供として、フッターにサイトマップを設置してユーザビリティを補ってまいります。
